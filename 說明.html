業務進度板
使用說明　│　班級聯絡簿與作業訂正追蹤

這是一個網頁工具，用來把每天的聯絡簿投影在教室螢幕上， 順便追蹤每個人的作業訂正有沒有完成。 不用下載、不用安裝、不用註冊、不用錢，把網址存成書籤就能開始用。

初 階
先會用就好
在自己班上發布聯絡簿、追蹤訂正進度。 只要會用瀏覽器就行，五分鐘看完。
進 階
還想多做一點
換電腦也看得到同一份資料、 讓家長用手機看孩子的聯絡簿。要多花點時間設定。
不確定要看哪邊 先看初階就好。進階的東西不設定，程式一樣完整可以用， 只是資料只留在你這一台電腦。等用順手了再回來看也不遲。
第 一 部 分
基本功能
在班上發布聯絡簿、追蹤作業訂正。這一部分看完就夠用了。

1開始使用

  1. 打開網址 第一次會跳出一個小視窗問你要不要載入示範資料。 建議先按「載入示範資料看看」，裡面有假的 24 個學生， 可以隨便亂點試試看，不會弄壞任何東西。
  2. 試玩完，清乾淨 上方點「設定」，往下找到「新學年重新建檔」按下去， 示範資料就清掉了。
  3. 填上你的班級名稱 設定的第一區「基本資料」：
    • 單位名稱　例如「光明國小　六年二班」
    • 副標題　隨便寫，或留空
    • 承辦人　填你的名字
  4. 貼上學生名單 第二區「員工名冊」的左邊那個大格子，一行一個人，這樣寫： 
    1 王小明 1
2 李小華 1
3 張小美 2
4 陳大文 2
    前面是座號，中間是姓名，最後是第幾組。組別要用阿拉伯數字（1、2、3）， 寫「第一組」它會排不好。
    右邊那格可以幫每一組取名字（例如「晨星科技」），不想取就空著。
  5. 按右上角「儲存設定」 完成了。上方點「營運月報」，點一下今天的日期就可以開始用。
設定頁一定要按「儲存設定」才算數 在設定頁打的東西（班級名稱、名冊、組別）都要按過右上角的 「儲存設定」才會真的寫進去。
只要你動過任何一格還沒存，那顆按鈕就會變成橘色、閃著「尚未存檔」提醒你， 在你按下去之前，程式不會去動你正在打的內容—— 就算中途切去別的分頁、或雲端剛好同步回來，打到一半的名單也還在。

順便挑一下用詞

設定第一區最下面有個「情境用語」的下拉選單，有四種說法可以選：

企業簽核版接案 → 待簽核 → 蓋「核准」章（預設）
公務機關版交辦 → 陳核 → 蓋「照准」章
品管驗收版投產 → 待檢驗 → 蓋「允收」章
白話直說版今日作業 → 今日訂正 → 蓋「完成」章

選哪個都不影響功能，換了整個畫面的字就跟著換。 中低年級或不想玩情境的話，選白話直說版最單純。

覺得畫面太方正？可以換

同一區還有一個「介面風格」，兩種選一種，選了立刻就看得到：

公文體 直角、明體。像一份正式的公文卷宗，配合情境用語最搭（預設）。
親和體 圓角、黑體。線條柔和、字的筆畫比較粗，投影出去遠遠看比較清楚， 中低年級用這個會好讀很多。

兩種都保留紙張紋理、朱砂印章、獎狀跟裝訂孔，卷宗的味道不會不見， 差別只在圓角跟字體。這是每台電腦各自的設定，你選的不會影響別人。

旁邊還有一個「慶祝方式」：

熱鬧版 全班完成或名單清空時，灑彩帶＋一段歡樂的小號音效（預設）。
莊重版 不灑彩帶，只有原本沉穩的蓋印音效。怕吵或需要安靜的場合選這個。

右上角的 ♪ 一樣可以把所有聲音關掉。電腦如果設定了「減少動態效果」， 彩帶也會自動不放。

2每天怎麼用

早上 點「今日工作單」，點一下上半區，把今天要抄的聯絡簿內容打進去，一行一項。
某一行前面加一個 *，那一行就會變成紅色的提醒（例如「明天帶水壺」）。
批改完 點一下下半區，把今天要訂正的作業打進去。
每打一項，全班每個人就會多出一個空格子等著蓋章。
訂正的時候 點「簽核進度」。誰完成了就點他那一格，會蓋上一個紅章。
點錯了再點一次就取消。
點組別的標題可以整組一次全部蓋完或全部取消。
有些人本來就不用訂正？直接幫他點掉就好。
全班都完成 自動跳出一張獎狀和音效。點旁邊或按 Esc 關掉。
欠很久的人 畫面下方有一個紅色的「催件名單」，把他加進去。
點他的名字可以列出他還欠哪幾樣，補一樣打勾一樣， 全部補完按「予以結案」就移出名單。
名單清空的時候會再跳一張金色的獎狀。
隔天 昨天沒完成的，會自動變成工作單最下面一條小字， 直接寫出是哪幾位同學，不會佔掉整個版面。

幾個好用的地方

  • 投影的時候字會自動放大填滿螢幕，項目少的時候字特別大。右上角 Ａ＋ Ａ− 可以再微調。
  • 學生換組別？直接用滑鼠把名字拖到別組去就好。
  • 鍵盤 1 2 3 4 切換上面四個分頁， ← → 換日期。
  • 右上角的 ♪ 可以關掉音效。
  • 連續好幾天全班都完成，月曆上方會浮出一面金色小旗子。
畫面太大或太小的時候 每間教室的電腦、螢幕、投影機都不一樣，同一個畫面在你這裡剛剛好， 在隔壁班可能就擠成一團。
這時候按住鍵盤的 Ctrl，同時滾動滑鼠滾輪， 就可以把整個網頁放大或縮小，調到你自己看得最舒服的大小：
  • Ctrl + 滾輪往上＝放大（字變大，適合投影給全班看）
  • Ctrl + 滾輪往下＝縮小（一次看到更多人，適合自己點名）
  • Ctrl + 0＝恢復原本的大小
瀏覽器會記住你調過的倍率，下次打開還是一樣，不用每天重調。
「簽核進度」跟「今日工作單」這兩頁的人數、項目數各班差很多， 用這招調一下通常就能一眼看完整頁、不用捲來捲去。

想給別人看看、或自己試玩

設定頁的「載入示範資料」會把畫面換成 24 位假學生的樣本。
如果你班上已經有資料，按下去不會直接覆蓋，而是先問你一次，然後切換成 示範模式：

  • 進去之前會自動存一份復原點。
  • 如果你有接雲端，連線會暫時中斷——示範期間怎麼亂點， 雲端和其他電腦上的班級都不會被動到。
  • 畫面右上角會出現橘色的「示範模式　點此還原」。看完點它， 資料和連線就整份回來了。

3非常重要：記得備份

請務必看完這一段 你的資料是存在這一台電腦的這個瀏覽器裡面。
關掉分頁、關機、隔天再開，資料都還在，這沒問題。
但是——換一台電腦、換一個瀏覽器、或是有人清理了瀏覽紀錄，資料就沒了， 而且救不回來。
按錯了還有一次機會 「載入示範資料」、「新學年重新建檔」、「匯入備份檔」這三個會整份換掉資料的動作， 程式都會先自動存一個復原點。
按完之後如果發現不對，回到「設定 → 資料保存」，會看到一條金色的 「有一份可以復原的紀錄」，按「復原成這一份」就整份救回來， 接著雲端也會跟著回到那一版。
復原之後還會再存一個新的復原點，所以就算復原錯了也能再換回去。
不過復原點只有最近一次，而且一樣存在這台電腦的瀏覽器裡—— 它是救急用的，取代不了每週備份。

所以請養成習慣：每個禮拜五，到「設定 → 資料保存」按一下 「匯出備份檔」。它會下載一個檔案，把它丟到你的 Google 雲端硬碟或隨身碟收好。

萬一資料真的不見了，或是要換電腦，就在新電腦上打開同一個網址， 按「匯入備份檔」，選那個檔案，資料就回來了。

怕忘記的話 第二部分有教怎麼接上 Google 試算表自動保存，就不用每週手動備份了。 但那個要花約十五分鐘設定，看你要不要。

4新學年、轉學生

中途轉來轉走 直接去「設定 → 員工名冊」改就好。 插一個人進去、刪掉一個人、調座號，以前的紀錄都不會亂掉。
新學年重新開始 「設定 → 資料保存 → 新學年重新建檔」。 按下去會先自動下載一份舊資料的備份再清空， 只留下班級名稱。然後貼上新的名單就好。
同一台電腦兩個班 在網址最後面加上 ?c=602（602 換成你要的代號）， 就會變成完全獨立的另一份。把兩個網址各存一個書籤。

5常見問題

投影出來字太小／太大、畫面擠在一起要一直捲
工作單那一頁右上角有 Ａ＋ Ａ−，只調工作單的字。
要調整個網頁的話：按住 Ctrl 再滾滑鼠滾輪 （往上放大、往下縮小，Ctrl+0 回復原狀）。 瀏覽器會記住，下次開還是一樣。詳見前面「畫面太大或太小的時候」。
左上角日期的 ◀ ▶ 箭頭被旁邊的字蓋住
畫面放得比較大的時候，副標題會自動收起來把位置讓出來， 箭頭不會再被壓到。如果還是覺得擠，用 Ctrl + 滾輪縮小一點就好。
昨天的紀錄不見了
先確認是不是換了一台電腦或換了瀏覽器——資料不會跟著人跑。 如果是同一台同一個瀏覽器卻不見了，可能是瀏覽器被清理過， 這時候只能靠備份檔還原。
不小心把資料弄不見了（按到示範資料、重新建檔、匯入錯的檔）
到「設定 → 資料保存」，金色那一條按「復原成這一份」。
如果是示範模式，直接點右上角橘色的「示範模式　點此還原」更快。
不小心按到「新學年重新建檔」
它按下去之前會先幫你下載一份備份， 去「下載」資料夾找那個檔案，用「匯入備份檔」救回來。
改了東西但畫面沒變
按 Ctrl + Shift + R 重新整理一次。
名冊打到一半，字整批不見、變回原本的名單
這是舊版的問題，已經修好了。
先按 Ctrl + Shift + R 重新整理， 確認網頁是最新版本再打一次。
新版在你動過設定頁之後，右上角的按鈕會變橘色顯示「尚未存檔」， 在你按下「儲存設定」之前，不論是切換分頁還是雲端同步， 都不會再去動你打的內容。
字太方正、看起來太嚴肅
「設定 → 基本資料 → 介面風格」改成親和體，圓角加大、字換成黑體。 用詞跟功能完全不變。
慶祝的彩帶或音效太吵
「設定 → 基本資料 → 慶祝方式」改成莊重版，就不灑彩帶、 音效也回到原本沉穩的蓋印聲。要全部靜音的話按右上角的 ♪。
學生會不會亂改？
會，程式沒有上鎖。所以建議由你自己或固定的幹部操作， 畫面就投在大家眼前，改了什麼大家都看得到。

進階功能
兩件事：一是讓你在不同電腦看到同一份資料，二是讓家長用手機看孩子的聯絡簿。 兩個都是選用的，不設定完全不影響前面的功能。

6讓不同電腦看到同一份資料

預設每台電腦各記各的：教室電腦記教室的，辦公室電腦記辦公室的，互相看不到。

想讓它們共用同一份，就要找一個大家都連得到的地方存資料。 這裡用你自己的 Google 試算表——資料放在你自己的雲端硬碟， 不會經過我，也不會經過任何別人。

順帶一提，接上之後就不用每週手動備份了，它會自動存。

  1. 開一份新的 Google 試算表 在瀏覽器網址列輸入 sheets.new 按 Enter， 會直接開一份新的空白試算表。左上角幫它取個名字，例如「六年二班　進度板」。
  2. 打開「Apps Script」 在試算表最上面那排選單找到 擴充功能，點進去選 Apps Script。 會跳出一個新分頁，裡面有一片空白的程式碼區域。
  3. 把裡面原本的東西全部刪掉 在那片程式碼區域裡點一下，按 Ctrl+A 全選， 再按 Delete 刪掉。
  4. 複製下面這段，貼進去 按下右邊的「複製全部」，然後回到剛剛那片空白區域按 Ctrl+V 貼上。
    要複製的程式碼 
    /**********************************************************************
 * 業務進度板 —— Google 試算表後端
 *
 * 用途：讓多台電腦共同編輯同一份紀錄，並提供家長專屬的唯讀檢視。
 * 安裝：見「說明.html」的圖文教學。簡單講就是
 *        試算表 → 擴充功能 → Apps Script → 貼上這整份 → 部署為網頁應用程式
 *
 * 資料存放：JSON 檔存在這份試算表旁邊的 Drive 資料夾裡，
 *          試算表本身只放一份「看得懂的檢視表」（可隨時手動更新）。
 *
 * 這份程式不會把資料傳給任何第三方，全部留在老師自己的 Google 帳號裡。
 **********************************************************************/

/* ---------------------------------------------------------------------
   選用：連線密碼
   留空 = 只要知道網址的人都能讀寫（網址很長很難猜，但畢竟是公開的）。
   想多一層保護的話，在這裡填一段自訂密碼，例如 'ming2026'，
   然後在程式的「共用連線」欄位貼成：
       https://script.google.com/macros/s/XXXX/exec?k=ming2026
   家長頁不受影響，家長仍然只用自己的六碼代碼。
   --------------------------------------------------------------------- */
var ACCESS_KEY = '';

var PROP_FILE = 'BOARD_FILE_ID';
var PROP_REV  = 'BOARD_REV';
var DATA_NAME = '業務進度板_資料.json';
var PREV_NAME = '業務進度板_資料_前一版.json';
var PROP_PREV = 'BOARD_PREV_ID';
var TZ        = 'Asia/Taipei';
var LOCK_MS   = 25000;

/* ==================================================================
   對外入口
   ================================================================== */

function doPost(e) {
  var out;
  try {
    var body = JSON.parse(e.postData.contents);
    out = route_(body, (e && e.parameter) || {});
  } catch (err) {
    out = { ok: false, error: String(err) };
  }
  return json_(out);
}

function doGet(e) {
  var p = (e && e.parameter) || {};
  if (p.action) return json_(route_(p, p));
  return HtmlService.createHtmlOutput(
    '<div style="font-family:sans-serif;padding:28px;line-height:1.8">' +
    '<h2 style="margin:0 0 10px">業務進度板 —— 後端運作中 ✓</h2>' +
    '<p>部署成功了。請把<b>目前這一頁的網址</b>複製起來，' +
    '貼進程式「設定 → 肆、共用連線」的欄位裡。</p>' +
    '<p style="color:#777;font-size:.9em">網址結尾應該是 <code>/exec</code>。' +
    '這一頁沒有任何資料，可以放心關掉。</p></div>'
  );
}

function route_(body, query) {
  switch (body.action) {
    case 'ping':
      return { ok: true, ver: 1, time: stamp_(), locked: !!ACCESS_KEY };
    case 'get':
      if (!authed_(query, body)) return { ok: false, error: 'auth' };
      return read_();
    case 'put':
      if (!authed_(query, body)) return { ok: false, error: 'auth' };
      return write_(body);
    case 'parent':
      return parentView_(body);          /* 家長端用自己的六碼代碼，不需要連線密碼 */
    default:
      return { ok: false, error: 'unknown action' };
  }
}

function authed_(query, body) {
  if (!ACCESS_KEY) return true;
  var k = (query && query.k) || (body && body.key) || '';
  return String(k) === String(ACCESS_KEY);
}

function json_(o) {
  return ContentService.createTextOutput(JSON.stringify(o))
    .setMimeType(ContentService.MimeType.JSON);
}

function stamp_() {
  return Utilities.formatDate(new Date(), TZ, 'yyyy-MM-dd HH:mm:ss');
}
function todayStr_() {
  return Utilities.formatDate(new Date(), TZ, 'yyyy-MM-dd');
}

   讀寫
   ================================================================== */

function fileByProp_(propKey, name, createIfMissing) {
  var props = PropertiesService.getScriptProperties();
  var id = props.getProperty(propKey);
  if (id) {
    try { return DriveApp.getFileById(id); } catch (err) { /* 檔案被刪掉了 */ }
  }
  if (!createIfMissing) return null;
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var parents = DriveApp.getFileById(ss.getId()).getParents();
  var folder = parents.hasNext() ? parents.next() : DriveApp.getRootFolder();
  var f = folder.createFile(name, '{}', 'application/json');
  props.setProperty(propKey, f.getId());
  return f;
}

function dataFile_(createIfMissing) {
  return fileByProp_(PROP_FILE, DATA_NAME, createIfMissing);
}

/* 覆蓋前的上一版。萬一有人在某台電腦上誤按「載入示範資料」之類的動作，
   把整個班級洗掉又同步上來，可以從試算表選單整份救回去。 */
function prevFile_(createIfMissing) {
  return fileByProp_(PROP_PREV, PREV_NAME, createIfMissing);
}

function read_() {
  var props = PropertiesService.getScriptProperties();
  var rev = Number(props.getProperty(PROP_REV) || 0);
  var f = dataFile_(false);
  if (!f) return { ok: true, rev: 0, data: null };
  try {
    var txt = f.getBlob().getDataAsString('UTF-8');
    var data = JSON.parse(txt);
    if (!data || !data.students) return { ok: true, rev: rev, data: null };
    return { ok: true, rev: rev, data: data };
  } catch (err) {
    return { ok: true, rev: rev, data: null };
  }
}

function write_(body) {
  var lock = LockService.getScriptLock();
  if (!lock.tryLock(LOCK_MS)) return { ok: false, error: 'busy' };
  try {
    var props = PropertiesService.getScriptProperties();
    var rev = Number(props.getProperty(PROP_REV) || 0);
    var sent = Number(body.rev || 0);

    /* 版本不一致 —— 有人搶先存過了，把雲端目前的內容送回去讓程式自己合併 */
    if (sent !== rev) {
      var cur = read_();
      return { ok: false, conflict: true, rev: cur.rev, data: cur.data };
    }
    if (!body.data || !body.data.students) return { ok: false, error: 'empty data' };

    /* 先把即將被覆蓋的內容抄一份到「前一版」，再寫入新的 */
    try {
      var old = dataFile_(false);
      if (old) {
        prevFile_(true).setContent(JSON.stringify({
          rev: rev,
          savedAt: Utilities.formatDate(new Date(), TZ, 'yyyy-MM-dd HH:mm:ss'),
          data: JSON.parse(old.getBlob().getDataAsString('UTF-8'))
        }));
      }
    } catch (errPrev) { /* 留存失敗不影響正常寫入 */ }

    dataFile_(true).setContent(JSON.stringify(body.data));
    rev = rev + 1;
    props.setProperty(PROP_REV, String(rev));
    noteStatus_(body.data, rev);
    return { ok: true, rev: rev };
  } catch (err) {
    return { ok: false, error: String(err) };
  } finally {
    lock.releaseLock();
  }
}

/* ==================================================================
   家長檢視 —— 只回傳該名學生的資料，其他同學的姓名與進度不會離開伺服器
   ================================================================== */

function parentView_(body) {
  var r = read_();
  var data = r.data;
  if (!data) return { ok: false, reason: 'nodata' };
  if (!data.prefs || !data.prefs.parent) return { ok: false, reason: 'closed' };

  var code = String(body.code || '').trim().toUpperCase();
  if (!code) return { ok: false, reason: 'bad' };

  var list = (data.students && data.students.list) || [];
  var me = null;
  for (var i = 0; i < list.length; i++) {
    if (String(list[i].code || '').toUpperCase() === code) { me = list[i]; break; }
  }
  if (!me) return { ok: false, reason: 'bad' };

  var days = data.days || {};
  var date = pickDate_(days, body.date);
  var rec = days[date] || { notes: [], cases: [], done: {}, watch: [] };

  var cases = (rec.cases || []).map(function (k) {
    return { text: k.text, done: !!(rec.done || {})[me.id + '|' + k.id] };
  });
  var notes = (rec.notes || []).map(function (n) {
    return { text: n.text, flag: !!n.flag };
  });

  /* 這孩子的補件清單（若有被列入催件名單） */
  var owing = [];
  var fl = (data.flags || {})[me.id];
  if (fl && !fl.gone) {
    owing = (fl.items || []).filter(function (it) { return !it.done; })
                            .map(function (it) { return it.text; });
  }
  var watched = (rec.watch || []).indexOf(me.id) >= 0;

  /* 最近十個有派工的上班日，給家長看趨勢 */
  var hist = Object.keys(days).filter(function (d) {
    return d <= date && (days[d].cases || []).length;
  }).sort().slice(-10).map(function (d) {
    var rr = days[d], total = (rr.cases || []).length, done = 0;
    (rr.cases || []).forEach(function (k) {
      if ((rr.done || {})[me.id + '|' + k.id]) done++;
    });
    return { date: d, total: total, done: done };
  });

  return {
    ok: true,
    org: { name: (data.org && data.org.name) || '', sub: (data.org && data.org.sub) || '',
           teacher: (data.org && data.org.teacher) || '' },
    lex: (data.prefs && data.prefs.lex) || 'corp',
    date: date,
    today: todayStr_(),
    dates: Object.keys(days).filter(function (d) {
      return (days[d].notes || []).length || (days[d].cases || []).length;
    }).sort(),
    student: { seat: me.seat || '', name: me.name || '' },
    notes: notes,
    cases: cases,
    owing: owing,
    watched: watched,
    history: hist
  };
}

/* 預設顯示今天。今天還沒發布的話，挑「離今天最近」的一天：
   通常就是昨天，但若老師已先把明天的內容準備好，就顯示明天。
   距離一樣時以過去那天為準。 */
function pickDate_(days, want) {
  if (want && days[want]) return want;
  var t = todayStr_();
  var has = function (d) {
    return days[d] && ((days[d].notes || []).length || (days[d].cases || []).length);
  };
  if (has(t)) return t;
  var ms = function (d) { return new Date(d.replace(/-/g, '/')).getTime(); };
  var base = ms(t);
  var best = null, bestGap = Infinity;
  Object.keys(days).forEach(function (d) {
    if (!has(d)) return;
    var gap = Math.abs(ms(d) - base);
    if (gap < bestGap || (gap === bestGap && ms(d) < base)) { best = d; bestGap = gap; }
  });
  return best || t;
}

/* 從選單執行：把雲端資料整份退回上一版。
   例如某台電腦誤按了會清空資料的動作、又同步上來的時候。 */
function restorePrev() {
  var ui = SpreadsheetApp.getUi();
  var pf = prevFile_(false);
  if (!pf) { ui.alert('目前沒有可以還原的前一版。'); return; }

  var snap;
  try { snap = JSON.parse(pf.getBlob().getDataAsString('UTF-8')); }
  catch (err) { ui.alert('前一版的檔案讀不出來。'); return; }
  if (!snap || !snap.data || !snap.data.students) {
    ui.alert('目前沒有可以還原的前一版。'); return;
  }

  var cur = read_();
  var nOld = (snap.data.students.list || []).length;
  var dOld = Object.keys(snap.data.days || {}).length;
  var nNow = cur.data ? (cur.data.students.list || []).length : 0;
  var dNow = cur.data ? Object.keys(cur.data.days || {}).length : 0;

  var ans = ui.alert(
    '還原雲端前一版',
    '目前雲端：' + nNow + ' 人、' + dNow + ' 個工作日\n' +
    '前一版：　' + nOld + ' 人、' + dOld + ' 個工作日' +
    '（存於 ' + (snap.savedAt || '未知時間') + '）\n\n' +
    '要把雲端還原成前一版嗎？\n' +
    '還原後，各台電腦下次同步就會拿到這一版。',
    ui.ButtonSet.YES_NO);
  if (ans !== ui.Button.YES) return;

  var lock = LockService.getScriptLock();
  if (!lock.tryLock(LOCK_MS)) { ui.alert('系統忙碌中，請稍後再試一次。'); return; }
  try {
    var props = PropertiesService.getScriptProperties();
    var rev = Number(props.getProperty(PROP_REV) || 0);
    /* 把「現在這一版」換到前一版的位置，這樣還原本身也可以再還原一次 */
    if (cur.data) {
      pf.setContent(JSON.stringify({
        rev: rev,
        savedAt: Utilities.formatDate(new Date(), TZ, 'yyyy-MM-dd HH:mm:ss'),
        data: cur.data
      }));
    }
    dataFile_(true).setContent(JSON.stringify(snap.data));
    rev = rev + 1;
    props.setProperty(PROP_REV, String(rev));
    noteStatus_(snap.data, rev);
  } finally {
    lock.releaseLock();
  }
  ui.alert('已還原　' + nOld + ' 人、' + dOld + ' 個工作日。\n\n' +
           '請到各台電腦按一下右上角的狀態標記（或重新整理）取得新版本。');
}

function buildDaily_(data) {
  var sh = sheet_('每日紀錄');
  sh.clear();
  var students = data.students.list || [];
  var rows = [['日期', '星期', '新案件數', '待簽核件數', '已核准格', '總格數', '完成率', '催件人數']];
  var W = ['日', '一', '二', '三', '四', '五', '六'];
  Object.keys(data.days || {}).sort().forEach(function (ds) {
    var d = data.days[ds];
    var cases = (d.cases || []).length;
    var total = cases * students.length, done = 0;
    students.forEach(function (s) {
      (d.cases || []).forEach(function (k) {
        if ((d.done || {})[s.id + '|' + k.id]) done++;
      });
    });
    var w = W[new Date(ds.replace(/-/g, '/')).getDay()];
    rows.push([ds, w, (d.notes || []).length, cases, done, total,
               total ? Math.round(done / total * 100) / 100 : '',
               (d.watch || []).length]);
  });
  sh.getRange(1, 1, rows.length, 8).setValues(rows);
  sh.getRange(1, 1, 1, 8).setFontWeight('bold').setBackground('#e6d9bc');
  if (rows.length > 1) sh.getRange(2, 7, rows.length - 1, 1).setNumberFormat('0%');
  sh.setFrozenRows(1);
  sh.autoResizeColumns(1, 8);
}

  var rows = [['日期', '座號', '姓名', '組別', '未完成項目']];
  var keys = Object.keys(data.days || {}).sort();

    (d.cases || []).forEach(function (k) {

    var f = flags[sid], s = byId[sid];

  sh.getRange(1, 1, 1, 5).setFontWeight('bold').setBackground('#f3d5d1');
  sh.setFrozenRows(1);
  sh.autoResizeColumns(1, 5);

自動同步、還是手動同步？

預設是自動：你一改動，過兩秒就自己上傳，其他電腦約二十秒內看到。多數情況用這個就好。

如果教室網路不穩、或你不希望它一直在背景連線，可以到 「設定 → 共用連線 → 同步方式」改成手動：

  • 平常只存在這台電腦，完全不連線，操作最順。
  • 有還沒上傳的東西時，右上角會變成橘色的 「⟳ 有未同步的變更」，點一下就送出去。
  • 忘記按就關視窗的話，瀏覽器會跳出提醒。
手動模式要記得一件事 沒按同步之前，家長頁和其他電腦看到的都還是舊資料。 要給家長看之前，記得先點一下右上角。

兩個前提 一、要先完成上面第 6 節，家長頁是去雲端讀資料的。
二、第 6 節的密碼一定要設好。家長連結裡會帶著你的雲端位址， 沒設密碼的話，稍微懂技術的人拿到連結就能反過來看到全班資料。 你按下啟用的時候，程式也會幫你檢查一次。
  1. 啟用 「設定 → 家長檢視」，勾選「啟用家長檢視」， 再按「產生／補發代碼」。每個學生後面就會出現一組代碼。
  2. 把連結交給家長（三種方式挑一種）
    • 印 QR 通知單（最省事）　按「列印 QR 通知單」， 會排好一張張小卡，每頁八張，A4 印出來沿虛線剪開，發給學生帶回家。 家長用手機相機一掃就開了，不用打字。
    • 傳 LINE　每個人後面都有「複製連結」，點了就複製好，貼給那位家長。
    • 做成對照表　按「複製全部連結」，貼進 Excel 或 Google 試算表， 就是一份座號、姓名、連結的清單。
QR 是程式自己畫的 沒有經過任何線上產生器，你的家長連結不會被送到別的網站去。
想停掉 把勾勾取消就好。所有連結立刻失效，不用改任何東西。
只想開給部分家長 連結是一個一個複製的，你發給誰、誰才看得到。沒發的人就等於沒開。
代碼被亂傳 按「全部重新產生」，舊的連結全部作廢，再重發一次。
新學年 名單換新之後，再按一次「產生／補發代碼」就好。
建議的做法 不要預設全班都發。先問問學校的規定， 再讓家長自己決定要不要，想要的再給連結。

8進階部分的常見問題

右上角一直是「本機保存」，沒有變綠色
網址沒填或填錯了。檢查一下：開頭是不是 https://script.google.com/，結尾是不是 /exec （不是 /dev），密碼那段是不是 ?k= 而不是別的符號。
出現橘色的「離線．僅存本機」
暫時連不到雲端，資料不會不見，還在這台電腦上， 網路好了會自己再試。一直這樣的話，去試算表的選單按「檢查安裝狀態」看看。
學校的帳號不給我「部署」
有些學校的 Google 帳號被管理員鎖住這個功能。 改用你自己的個人 Gmail 帳號開試算表就可以了。 或者就不做這一段，前面的功能完全不受影響。
右上角橘色的「⟳ 有未同步的變更」是什麼
你把同步方式設成手動了，表示有東西還沒上傳，點它一下就會送出去。 想改回自動，到「設定 → 共用連線 → 同步方式」。
右上角變成橘色的「待確認」
這台電腦是第一次連上這個網址，程式在等你選要留哪一份資料。 到「設定」或點一下那個橘色標記，視窗會再跳出來。 選好之前不會上傳任何東西，雲端上的資料很安全。
第二台電腦連上去以後，第一台的班級不見了
舊版才會這樣（新電腦上的示範資料會覆蓋雲端）。新版第一次連線一定會先問你。
如果已經發生了：在原本那台電腦上「設定 → 資料保存 → 匯入備份檔」， 把之前匯出的備份檔讀回來，再讓它上傳一次就會蓋回去。 平常有按週五備份的習慣，這種事就救得回來。
雲端上的資料被某台電腦洗掉了，怎麼救
三個地方都可以救，由近而遠：
一、出事的那台電腦：「設定 → 資料保存」按「復原成這一份」，救回來會自動傳上去。
二、試算表：打開你的 Google 試算表，上方選單 「業務進度板 → 還原雲端前一版」。程式每次覆蓋雲端之前， 都會自動把前一版另存一份，這裡可以整份退回去。還原完請各台電腦重新整理一次。
三、你的備份檔：任何一台電腦「匯入備份檔」，再讓它上傳一次。
兩台電腦同時在改，會不會打架
不會。改不同日期完全不衝突； 真的改到同一格，以比較晚改的那個為準。
家長說打開是「尚未開放」
「設定 → 家長檢視」的勾勾沒打開， 或是剛打開還沒同步上去。確認右上角是綠色的「雲端同步中」再試一次。
家長說「連結不完整」
連結被通訊軟體截斷了。重新用「複製連結」貼一次， 確認貼出去的網址裡有 &s= 那一段。

9資料到底放在哪裡

  • 沒有做第 6 節的話——資料只在你這台電腦的瀏覽器裡， 沒有任何人看得到，包括提供這個網址的人。
  • 做了第 6 節之後——資料存在你自己的 Google 雲端硬碟， 一樣不會經過別人。
  • 那個雲端網址是公開的，所以密碼一定要設。
  • 家長的每個連結只顯示一位學生，而且開關一關就全部失效。
  • 班級名單和作業紀錄算是學生的個人資料。 要不要放上雲端、要不要開放給家長，請先確認學校的規定。
